==============================================
  个人简历网页 — 使用说明书
==============================================

📁 文件说明
-----------
index.html  → 主页面，双击用浏览器打开即可看到简历
data.json   → 简历数据文件，修改这个文件就能更新简历内容
photo.jpg   → 你的头像照片（需要你自己准备，放在同一目录下）

🚀 如何查看
-----------
双击 index.html，浏览器会自动打开你的简历页面。

📝 如何修改内容（方法一：改文件）
----------------------------------
1. 用"记事本"或任何文本编辑器打开 data.json
2. 按照里面的格式，把你的真实信息替换进去
3. 保存文件，刷新浏览器页面即可看到更新

   格式说明：
   - 每个字段都有中文版和 _en 结尾的英文版
   - 例如 "school": "清华大学" 和 "school_en": "Tsinghua University"
   - 中英文内容都需要你自己填写
   - 删除某条记录：把那一整段（从 { 到 }）删掉即可
   - 新增某条记录：复制一条现有的，修改内容即可

📝 如何修改内容（方法二：网页编辑）
----------------------------------
1. 打开 index.html
2. 点击左下角"编辑模式"按钮
3. 右侧会出现编辑面板，提供以下功能：
   - "导出为 data.json 文件"：把当前数据下载到电脑
   - "导入 data.json 文件"：从电脑加载数据文件
   - "手动添加条目"：输入JSON数据新增一条记录
   - "恢复默认数据"：回到最开始的示例数据
4. 编辑模式下，点击任意卡片进入弹窗，底部会出现"编辑"和"删除"按钮

🌐 如何切换中英文
----------------
点击左下角"English"按钮，页面所有文字会切换为英文。
再点击"中文"按钮切换回来。

🖼 如何更换头像
--------------
1. 准备一张正方形照片，命名为 photo.jpg
2. 把照片放在与 index.html 同一个目录下
3. 如果想用其他文件名，修改 data.json 中 profile.avatar 的值

🌍 如何部署到网上让别人访问
--------------------------
（免费方案：GitHub Pages）

1. 注册一个 GitHub 账号：https://github.com
2. 创建一个新仓库，仓库名格式为：你的用户名.github.io
   例如用户名是 zhangsan，仓库名就是 zhangsan.github.io
3. 把 index.html、data.json、photo.jpg 上传到这个仓库
4. 等待1-2分钟，访问 https://你的用户名.github.io 就能看到了

更详细的步骤可以百度搜索"GitHub Pages 教程"。

💡 小提示
---------
- 修改 data.json 时注意不要删掉引号和逗号，否则页面可能显示不出来
- 如果改坏了，可以重新下载原始的 data.json 覆盖回去
- 网页编辑的内容保存在浏览器中，清除浏览器数据会丢失（可以随时导出备份）
- 建议用"导出JSON"功能定期备份你的数据
